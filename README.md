# Asteroids

## Wymagania systemowe

> [!WARNING]
> Terminal powinien wspierać kody ANSI. Uwaga: terminal środowiska IDLE nie posiada wsparcia kodów ANSI!

Dla lepszego doświadczenia zaleca się uruchamiać program w terminalu, który wspiera Unicode. Przykładami takich terminałów na systemie Windows są (Git) Bash oraz Windows Terminal.

Zauważono także, że bash na systemie Linux pozwala osiągnąć lepszych wyników kratek na sekundę, niż terminały na Windowsie. Jeśli jest możliwość testowania na Linuxie, to zaleca się z niej skorzystać dla jeszcze lepszego doświadczenia.

## Instrukcje uruchomienia

```bash
python main.py
```
